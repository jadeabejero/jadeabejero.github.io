Rules run top to bottom, and the first match wins, the same way Gmail filters do. Clients are checked first on purpose: an urgent message from a client that happens to mention an invoice should go to the person, not the bookkeeper. Anything no rule catches stays in the inbox for a human, because a triage system that guesses is worse than one that admits it doesn't know.
